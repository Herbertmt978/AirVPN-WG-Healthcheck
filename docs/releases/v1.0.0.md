# AirVPN WireGuard Healthcheck v1.0.0

This is the first stable, source-visible release of the AirVPN WireGuard
healthcheck.

## Highlights

- Detects a stale or inconsistent single-peer WireGuard tunnel even when the
  interface still appears to be up.
- Recovers with bounded restarts and optional credential-free AirVPN endpoint
  rotation.
- Treats endpoint changes as durable transactions and verifies tunnel, routing,
  egress, and configured qBittorrent binding postconditions before success.
- Installs hardened systemd units while preserving existing WireGuard and
  per-interface health-check configuration.
- Keeps speed checks, endpoint rotation, ICMP checks, and container repair disabled
  until explicitly configured.

## Install or upgrade

Download the attached `airvpn-wg-healthcheck-1.0.0.tar.gz` and `SHA256SUMS`,
verify the archive, and follow the release-oriented quick start in the README.
Existing installations must stop the timer and service and prove that no pending
rotation marker exists before replacing files.

## Release assets

- `airvpn-wg-healthcheck-1.0.0.tar.gz` - deployment source package for Linux.
- `airvpn-wg-healthcheck-1.0.0.zip` - the same curated package in ZIP form.
- `SHA256SUMS` - SHA-256 integrity checks for both attached packages.

The packages are produced from the tagged Git tree. They contain only the
installer, runtime files, configuration example, public documentation, version,
changelog, and these release notes. They never include local configuration,
credentials, logs, repository history, or generated state.

## Important boundaries

This service runs as root and is not a firewall kill switch. Review the installer,
configure an independent kill switch, and validate one manual service run before
enabling the timer. No license is granted by this release; public visibility does
not make the project open source.
